Privacy Policy

Last updated: November 11, 2026

This policy covers this website and GoodGridCo Publisher, the internal tool GoodGridCo uses to upload its own short videos to its own YouTube channel, TikTok account, Instagram account and Facebook Page. GoodGridCo is a small studio in Italy that sells printable puzzles and activities on Etsy.

Who uses GoodGridCo Publisher

Only GoodGridCo uses the tool, on its own computer, with its own accounts. The tool is not offered to other people or businesses and it never signs in to, reads or changes anyone else's account.

YouTube API Services

GoodGridCo Publisher uses YouTube API Services to upload GoodGridCo's own videos to the GoodGridCo YouTube channel. By using the YouTube features of the tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

When the GoodGridCo account owner signs in with Google, the tool asks only for the permission to upload videos (youtube.upload). It receives an access token and a refresh token. It does not request or read viewer data, comments, subscribers, analytics, playlists, messages or any data about other YouTube users.

What data the tool uses, and why

  • Sign-in tokens from YouTube, TikTok and Meta (Instagram and Facebook), used only to upload GoodGridCo's own videos and to check whether an upload has finished.
  • Basic account details of GoodGridCo's own accounts returned at sign-in (account or Page ID and name), used only to upload to the right account.
  • Upload results: the ID and link of each video GoodGridCo publishes, kept in a small local list so the tool never publishes the same video twice.

Where the data is stored and who it is shared with

Tokens are stored only on GoodGridCo's computer, in the operating system's encrypted keychain. The upload list is a local file on the same computer. Nothing is stored on any other server. Tokens and videos are sent only to the platform that issued the token (YouTube/Google, TikTok or Meta). We do not sell, rent or share any data with anyone else, and we do not use it for advertising.

Cookies

Neither this website nor GoodGridCo Publisher stores cookies or similar technologies on your device. This website is hosted on GitHub Pages; GitHub may keep technical logs such as IP addresses for security, as described in the GitHub Privacy Statement.

How to revoke access and delete data

Access can be revoked at any time:

  • Google / YouTube: Google security settings, third-party access.
  • TikTok: Settings and privacy › Security › Manage app permissions.
  • Meta: Facebook Settings › Business integrations, and Instagram Settings › Website permissions.

When access is revoked, the tokens stop working at once; we then delete them from the keychain. The only data kept from YouTube API Services is the ID and link of the videos we uploaded to our own channel, kept only to avoid uploading the same video twice. We do not keep any other YouTube API data. To ask for deletion of any data, write to goodgridco@gmail.com; we delete it within 7 days.

Children

The tool is used only by the GoodGridCo account owner, who is an adult. It does not collect data from children.

Changes and contact

If this policy changes, we update this page and the date at the top. Questions: goodgridco@gmail.com, or message us through our Etsy shop.
